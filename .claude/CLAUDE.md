# Claude グローバル設定

## スタイル

- コードや技術的な出力は英語のままで、それ以外の返答は日本語で行う
- 返答は簡潔にし、作業後に「〜しました」のような要約を書かない
- 絵文字は明示的に求められた場合のみ使う
- コードコメントは「なぜそうしているか」が自明でない場合のみ書く
- バッククォートで囲まれている場合を除き、日本語の単語と英単語の間には半角スペースを入れる
- 数字も英単語と同様に扱い、日本語との間に半角スペースを入れる
  - ただし「〜」の前後には入れない
- 丸括弧は半角文字を用いて、前後に半角スペースを入れる
- 句読点が隣接している場合は半角スペースは不要

## 作業方針

- API利用など、オンラインドキュメントを参照するのが適切な場面では、積極的にWeb検索する
- 新規ファイルを作るより既存ファイルを編集することを優先する
- タスクに必要な範囲を超えたエラーハンドリングや抽象化を加えない
- 危険・不可逆な操作 (`force push`、ファイル削除など) は実行前に確認を取る
- 明示的に頼まれない限りコミットしない

## ツール

- ブラウザでデバッグする場合は、Chrome ではなく`agent-browser`を使用する
  - `AGENT_BROWSER_PROFILE`で profile を固定しているので、Google などのログイン状態は永続化されている。`--profile`や`--session`は指定しない
  - ログインが必要な画面に遭遇したら、認証情報を扱わず、ユーザーに`agent-browser --headed true open https://accounts.google.com/`で手動ログインしてもらう。
  - profile ディレクトリ (`~/.agent-browser/profiles/claude`) は削除しない。
- `.devcontainer/`があればビルドツールなどはコンテナにインストールされているので、下記のコマンドで実行する。
  - `devcontainer exec --workspace-folder . <コマンド>`
